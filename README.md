Fx & Metric Converter
Fx & Metric Converter is a high-precision, responsive web utility designed for global travelers, traders, and real estate professionals. It provides real-time currency exchange rates alongside a comprehensive suite of metric conversions, including specialized Indian regional land measurements.

🚀 Features
1. Forex Exchange (FX)
Live Rates: Integrated with the ExchangeRate-API for real-time global currency data.

Global Support: Includes a wide range of international currencies (USD, INR, EUR, GBP, AED, etc.).

Clean Display: Shows the converted amount clearly with the specific live exchange rate used.

2. Land Area Converter
Indian Regional Units: Native support for traditional measurements used across India:

Guntha, Bigha, Biswa, and Kanal.

Global Standards: Instantly convert to and from:

Acres, Hectares, Sq. Meters, Sq. Yards, and Sq. Feet.

Real-time Sync: Update any single field, and all other regional/standard units recalculate instantly.

3. Unit Metrics
Length/Distance: Supports conversions for Inch, Feet, Centimeters, Meters, Kilometers, and Miles.

Mass & Volume: Quick conversion for Kilograms (KG), Pounds (LB), Litres (L), and Gallons (US).

🎨 User Experience (UX)
Glassmorphic Design: A modern, clean interface with a soft-blue "FinTech" aesthetic.

Intuitive Layout: Card-based dashboard with center-aligned headers and capitalized labels for high readability.

Responsive Design: Optimized for Desktop, Tablet, and Mobile views.

Input-Driven Logic: No need to click "Calculate" for metrics—results ripple through the UI as you type.

🛠️ Technology Stack
HTML5: Semantic structure.

CSS3: Custom properties (CSS variables), Grid layout, and Flexbox for responsiveness.

JavaScript (ES6+): Async/Await for API calls and dynamic mathematical logic.

Google Fonts: "Plus Jakarta Sans" for professional typography.

API: ExchangeRate-API for live currency data.

🌍 Indian Land Unit Reference
Because land measurements vary by region in India, this application uses the most common standard conversions:

1 Bigha ≈ 2529.28 Sq. Meters (Standard/UP)

1 Guntha = 101.17 Sq. Meters

1 Kanal = 505.85 Sq. Meters

1 Biswa = 126.44 Sq. Meters
